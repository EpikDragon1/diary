# 🧪 Тестирование электронного дневника

## Как запустить

1. Убедитесь, что `agent-desktop-ffi` скачан в папку `diary_project/`
2. Откройте PowerShell в папке `diary_project/`
3. Запустите:
   ```powershell
   python test_diary_full.py
   ```

## Что делает скрипт

- ✅ Открывает браузер с дневником
- ✅ Проверяет загрузку страницы
- ✅ Проверяет форму входа
- ✅ Проверяет расписание (номера уроков и время)
- ✅ Выводит итоги тестирования

## Ручное тестирование

Для полного тестирования нужно вручную:
1. Войти как ученик → проверить расписание
2. Войти как учитель → проверить журнал
3. Войти как директор → проверить управление
4. Войти как родитель → проверить статистику ребёнка
