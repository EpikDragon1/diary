# 🧪 Инструкция по тестированию электронного дневника

## 📋 Что тестировать

### 1. 🔐 Авторизация и роли

#### Вход для администраторов
- [ ] Открыть "Вход для администраторов"
- [ ] Ввести логин: `admin`, пароль: `admin`
- [ ] Убедиться, что открывается панель администратора
- [ ] Проверить, что admin видит только "Панель управления" и "Школы"
- [ ] Проверить, что admin НЕ видит "Настройки"

#### Вход для директоров
- [ ] Создать директора через админку (или использовать тестовые аккаунты)
- [ ] Войти через обычный вход
- [ ] Убедиться, что директор видит: Панель управления, Справку, Настройки
- [ ] Убедиться, что директор НЕ видит "Школы"
- [ ] Проверить, что директор может управлять учителями, учениками, расписанием

#### Вход для учителей
- [ ] Войти как учитель
- [ ] Убедиться, что учитель видит только учеников из своих классов
- [ ] Проверить, что учитель может ставить оценки только по своим предметам

#### Вход для учеников
- [ ] Войти как ученик
- [ ] Убедиться, что ученик видит только СВОИ оценки
- [ ] Проверить расписание своего класса
- [ ] Проверить домашние задания

#### Вход для родителей
- [ ] Войти как родитель
- [ ] Убедиться, что родитель видит ВСЕ оценки ребёнка
- [ ] Проверить статистику ребёнка
- [ ] Проверить расписание ребёнка

---

### 2. 🏫 Управление школами (только админ)

- [ ] Создать новую школу
- [ ] Назначить директора школе
- [ ] Переключиться между школами
- [ ] Удалить школу (с подтверждением)
- [ ] Проверить, что директор НЕ может создавать/удалять школы

---

### 3. 👨‍🏫 Управление учителями (директор)

- [ ] Добавить учителя
- [ ] Проверить, что у учителя есть login/password
- [ ] Назначить учителя классу
- [ ] Удалить учителя (с галочкой "удалить учеников/родителей")
- [ ] Проверить, что учитель может войти с сгенерированными данными

---

### 4. 👤 Управление учениками (директор, домашний учитель)

- [ ] Добавить ученика (вручную или импорт)
- [ ] Проверить, что у ученика есть login/password
- [ ] Проверить, что login генерируется автоматически
- [ ] Проверить, что password генерируется автоматически
- [ ] Изменить оценку ученику
- [ ] Проверить, что оценка "1" НЕ доступна в списке

---

### 5. 📅 Расписание

- [ ] Создать расписание для класса
- [ ] Проверить номера уроков (#1, #2, #3...)
- [ ] Проверить время уроков (08:00-08:45 и т.д.)
- [ ] Добавить предмет, учителя, кабинет
- [ ] Проверить, что ученик видит расписание своего класса
- [ ] Проверить, что учитель видит своё расписание
- [ ] Проверить, что родитель видит расписание ребёнка

---

### 6. 📊 Журнал оценок

- [ ] Поставить оценку (2, 3, 4, 5)
- [ ] Проверить, что оценка "1" НЕ доступна
- [ ] Проверить средний балл
- [ ] Проверить статистику оценок (распределение 2, 3, 4, 5)
- [ ] Проверить, что оценки синхронизируются между устройствами

---

### 7. 📝 Домашние задания

- [ ] Создать домашнее задание
- [ ] Выбрать предмет, класс, дату
- [ ] Проверить, что ученик видит задание
- [ ] Проверить, что задание отображается в правильном классе

---

### 8. 💾 Синхронизация данных

- [ ] Войти в одну школу с одного устройства
- [ ] Войти в ту же школу с другого устройства
- [ ] Изменить данные на одном устройстве
- [ ] Проверить, что изменения появились на другом устройстве
- [ ] Проверить, что данные сохраняются после перезагрузки страницы

---

### 9. 🔒 Безопасность

- [ ] Попытаться войти 5 раз с неправильным паролем
- [ ] Убедиться, что после 5 попыток происходит блокировка на 5 минут
- [ ] Проверить, что admin может войти ТОЛЬКО через "Вход для администраторов"
- [ ] Проверить, что директор может войти ТОЛЬКО через обычный вход
- [ ] Проверить согласие с политикой конфиденциальности (обязательный чекбокс)

---

### 10. ⚙️ Настройки

- [ ] Сменить пароль
- [ ] Экспорт данных в JSON
- [ ] Импорт данных из JSON
- [ ] Удалить аккаунт (с предупреждением)
- [ ] Проверить правовую информацию (лицензия MIT, 152-ФЗ)

---

### 11. 🎨 Интерфейс

- [ ] Проверить футер (не перекрывает кнопку "Выйти")
- [ ] Проверить политику конфиденциальности (нет китайских иероглифов)
- [ ] Проверить, что все кнопки работают
- [ ] Проверить адаптивность на мобильном (если возможно)
- [ ] Проверить, что навигация работает корректно

### 12. 🧪 Тестовые аккаунты

- [ ] Нажать "🧪 Создать тестовые аккаунты" на странице входа
- [ ] Проверить, что созданы: student1, teacher1, director1, parent1
- [ ] Пароль для всех: `test123`
- [ ] Войти как student1 → проверить данные
- [ ] Войти как teacher1 → проверить данные
- [ ] Войти как director1 → проверить данные
- [ ] Войти как parent1 → проверить данные

## 📸 Что присылать при ошибках

### 1. Скриншоты
- Скриншот всей страницы (не только части!)
- Скриншот консоли браузера (F12 → Console)
- Скриншот ошибок, если есть

### 2. Консоль браузера
1. Открой F12 (или правая кнопка → Проверить)
2. Перейди на вкладку "Console"
3. Скопируй все ошибки (красный текст)
4. Пришли скриншот или текст ошибок

### 3. Данные для воспроизведения
- Какая роль вошла (admin, teacher, student, parent, director)
- Какая школа выбрана
- Какие действия были выполнены (по шагам)
- Что ожидалось vs что произошло

### 4. Браузер и версия
- Какой браузер (Chrome, Яндекс, Firefox, Edge)
- Версия браузера (если знаешь)

### 5. URL страницы
- URL где происходит ошибка
- Например: `https://epikdragon1.github.io/diary/`
